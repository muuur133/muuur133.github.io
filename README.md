# Neon Auth

Учебный проект: одностраничное приложение с авторизацией через Firebase Authentication и хранением записей в Firebase Realtime Database. Дизайн — неоновый «synthwave»: тёмный фон с сеткой, светящиеся кнопки и панели.

## Возможности

- Вход через **GitHub** (редирект или всплывающее окно — режим выбирается в интерфейсе и сохраняется в localStorage) и **Google**
- Вход через **Email**:
  - по паролю (регистрация + вход);
  - без пароля (письмо со ссылкой для входа — email link)
- После входа открывается форма добавления записей и общий список всех записей
- Данные записей: название, описание, автор (`uid`), время создания (`serverTimestamp`)
- Список обновляется в реальном времени (Realtime Database, `onValue`)
- Состояние входа отслеживается через `onAuthStateChanged`, интерфейс переключается автоматически

## Технологии

- HTML5, CSS3 (нативный JavaScript без фреймворков)
- Firebase JS SDK (модули из CDN, ES-модули)
  - Firebase Authentication (OAuth-провайдеры, email/password, email link)
  - Realtime Database
- GitHub Pages как хостинг

## Настройка проекта

1. Создайте проект в [Firebase Console](https://console.firebase.google.com/).
2. Включите провайдеров: **Authentication → Sign-in method** → Google, GitHub, Email/Password, Email Link.
3. Для GitHub добавьте Client ID и Client Secret (создаются в GitHub → Settings → Developer settings → OAuth Apps).
4. В **Authentication → Settings → Authorized domains** добавьте домен, с которого открывается страница (например, `ваш-ник.github.io`).
5. Создайте **Realtime Database** и скопируйте `firebaseConfig` из настроек проекта в начало `script2.js`.

### Правила безопасности Realtime Database

Обязательно настройте правила — с дефолтными (`read/write: true`) база открыта всем:

```json
{
  "rules": {
    "items": {
      ".read": "auth != null",
      ".write": "auth != null",
      "$item": {
        ".validate": "newData.child('author').val() === auth.uid"
      }
    }
  }
}
```

Правило `author` не даёт подделать автора записи на клиенте.

## Запуск

Вариант 1 — GitHub Pages:

1. Создайте репозиторий, загрузите три файла.
2. Settings → Pages → деплой из ветки `main`.
3. Откройте `https://ваш-ник.github.io/имя-репозитория/` и добавьте этот домен в Authorized domains.

Вариант 2 — локально (модульный JS требует HTTP, просто открытие файла работать не будет):

```bash
npx serve .
# или
python -m http.server 8000
```

Затем откройте `http://localhost:8000` и добавьте `localhost` в Authorized domains Firebase.

## Известные особенности и ограничения

- Google-провайдер всегда использует редирект (без popup), GitHub — оба режима на выбор.
- Выпадающий список (`<select>`) в некоторых браузерах рисуется системным виджетом — кастомная тема опций применяется не везде.
- Вход по ссылке (email link) требует, чтобы поле `url` в `actionCodeSettings` совпадало с одним из Authorized domains.
- Список записей общий для всех пользователей; каждый может удалить/изменить свою запись только на уровне правил базы — полноценного редактирования в UI пока нет.
- Максимальный размер списка не ограничен — при большом объёме стоит добавить `limitToLast`.
